ResolveIT Complaint Management System — Live Demo

HOW TO RUN
1. Extract this ZIP file.
2. Open index.html in Chrome or Edge.
3. Click “Load demo data”.
4. Test registering a complaint, searching/filtering, changing status, editing, and deleting.

TECHNOLOGY: HTML, CSS, JavaScript, browser localStorage. No installation or server required.

LIMITATIONS: This is a front-end demo, not a deployed public website. Data is stored only in the current browser and is not shared with a server. It has no login, backend API, or MySQL database. Do not enter real or sensitive personal information.

PROJECT EXPLANATION
“I created a Complaint Management System using HTML, CSS, and JavaScript. Users can register complaints, set category and priority, search/filter records, edit or delete complaints, and update status. The dashboard shows total, open, in-progress, and resolved counts. This demo uses browser localStorage to preserve data on the same device. A future version could use Flask and MySQL for a backend and centralized storage.”
